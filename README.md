# PS4 11.00 Web Host for GitHub Pages

Цей репозиторій містить готовий вебхост для PlayStation 4 (прошивка 11.00).

## Як завантажити на GitHub:
1. Розархівуйте цей ZIP-архів.
2. Створіть новий публічний репозиторій на GitHub.
3. Перетягніть у нього вміст цієї папки (`index.html`, папку `payloads` та `README.md`).
4. Перейдіть у **Settings -> Pages**, у полі **Source** виберіть **Deploy from a branch** (гілка `main`), та натисніть **Save**.
5. Зачекайте 1-2 хвилини і відкрийте згенероване посилання в браузері PS4.
